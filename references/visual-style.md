# 黑墨金赭肖像视觉规范

依据用户提供的 8 张 2:3 竖幅头像提取。以下是视觉描述，不认定原作的具体画材、作者或官方风格名称。

## 构图

- 单人居中，正面或轻微侧转，头肩至胸部构图。保留源照片的视线、头部倾斜及表情，不强行摆正。
- 默认 2:3，头顶少量留空，肩部可伸至左右画边。头部最详细，衣服往下简化并自然收笔。
- 背景为空的暖白细纹纸，无场景、标题、奖章、头像圆框或装饰。

## 黑墨笔法

- 五官、脸缘、耳朵、眼镜和衣领由有粗细变化的墨线概括；允许断线、毛边与运笔停顿。
- 头发以顺着发型的弧形刷痕和成束墨线表现，密黑与飞白交替，保留干笔拖痕。
- 眉毛、发际线和胡须用短促、疏密变化的笔触；黑色实块集中在发根、瞳孔、鼻孔、耳廓及领口转折。
- 衣服仅保留关键轮廓、领口、翻领及少量褶线，内部纸白；不画复杂纹样和连续灰调。

## 金赭色塑形

- 金色呈哑光颜料或金粉笔触的视觉感，轻微颗粒、刷痕及浓淡变化，不是金属高光或发光效果。
- 阴影集中于太阳穴、脸侧、眼下、鼻侧、唇部、下巴和颈部。脸部用窄带、短弧线及少量不规则色块，下颌和颈部可有较大的色块。
- 额头中心、鼻梁与双颊中心保留纸白；不要把整张脸涂黄，也不画照片般连续肤色渐变。
- 金色块的边缘略不规则，避免柔光喷枪、水彩大面积漫染和机械矢量平涂。
- 默认少量金赭虹膜、黑色瞳孔、纸白眼白，眼形、眼距及目光依照源照片。用户要求保留原虹膜色时优先遵从。

## 配色锚点

色值是目测近似，参考图的整体观感优先；不是测量或色彩校准结果。

| 角色 | 近似色 | 用法 |
|---|---|---|
| 暖白纸 | `#F2F0E8` | 主导画面，纹理细微，不做明显泛黄旧纸 |
| 黑墨 | `#111110` | 结构线、头发与小面积深暗部 |
| 金赭 | `#C2A044` | 局部结构阴影 |
| 深赭金 | `#8C722D` | 下颌及颈部较深色块 |

## 人物保真

形体写实、笔法概括。保留脸型、五官比例、眼距、鼻形、嘴形、发型轮廓、年龄、眼镜形状及表情。舍弃毛孔和肤色连续层次，不改变人物身份。

没有眼镜或胡须就不添加，不照搬参考人物的年长特征。保留原照片的服装类别和领口，再以稀疏线条概括。参考图角落的小签名不属于必要风格元素，不复制、不伪造。

## 偏差与修正

| 偏差 | 修正 |
|---|---|
| 黄色滤镜覆盖全脸 | 让主要面部重新露出纸白，金赭只落在结构阴影 |
| 等宽矢量头像 | 增加墨线粗细、断线、干笔和飞白 |
| 金属浮雕、雕像 | 金色改为纸上哑光颜料，取消立体金属反射 |
| 满脸木刻排线 | 减少排线，改为纸白与选择性金赭块面 |
| 水彩漫染或柔光照片 | 使用明确墨线、有限色块和大片未着色区域 |
| 长相变成参考人物 | 重新强化新照片的脸型、五官、年龄与发型 |

## 验收

一眼可认出源人物；暖白、黑墨、金赭构成主要视觉；头发有干笔飞白；脸部有大片纸白；金色服务结构阴影；衣服明显简化；无参考签名、错误文字、多余配饰或明显人体错误。
